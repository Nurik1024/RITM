# Безопасность Ритма

## Вход и пароли

Вход на опубликованном сайте обслуживает платформа Sites через Sign in with ChatGPT. Приложение получает проверенный идентификатор пользователя от платформы. Пароли, хеши паролей, OAuth-токены и API-ключи в приложении не хранятся. За проверку пароля, восстановление доступа и противодействие перебору при входе отвечает провайдер авторизации; собственная регистрация по email и паролю здесь не реализована. Политики провайдера не проверялись этим аудитом.

Заголовки `oai-authenticated-user-*` считаются доверенными только за шлюзом Sites. При переносе на другой хостинг необходимо заново интегрировать проверку сессии и исключить прямую подстановку этих заголовков клиентом. Нельзя просто выставлять этот Worker напрямую в интернет без доверенного шлюза.

## Защита данных

- Каждая операция API проверяет вход и владельца записи на сервере. Идентификатор пользователя не принимается из JSON клиента.
- Drizzle формирует параметризованные SQL-запросы. Значения пользователя не вставляются в SQL как исполняемый текст.
- Изменения требуют совпадающий Origin, JSON Content-Type и ограничены 8192 байтами, включая потоковые тела запросов.
- API возвращает `Cache-Control: private, no-store`. Пароли и данные сессии не сохраняются в localStorage.
- Названия привычек выводятся через стандартное экранирование React, без raw HTML.
- Ограничения дат, расписания и владения проверяются сервером. Уникальность пары «привычка + дата» предотвращает повторное начисление опыта.
- Часовой пояс фиксируется при настройке аккаунта; менять его через API для обхода окна отметок нельзя.
- Рабочая D1-база находится отдельно от GitHub. В репозиторий и архив исходников не включаются локальная база, `.env`, `.dev.vars`, приватные ключи и служебные учётные данные публикации.

## Проверки

```sh
node --experimental-strip-types --test scripts/habits.test.ts scripts/product-test.mjs
npx tsc --noEmit --incremental false
node scripts/security-test.mjs http://127.0.0.1:5173
node scripts/security-isolation.mjs http://127.0.0.1:5173
npm audit --omit=dev
```

HTTP-проверки используют только локальный тестовый вход и изменяют тестовую локальную базу. Не запускайте их против рабочего сайта. Для проверки изоляции требуется локальная миграция D1. Локальный вход не включается в production-сборку. Проверены сценарии без авторизации, подмена заголовков, CSRF, некорректные данные, ограничения дат, повторные начисления и доступ к записям другого пользователя. Это ограниченная проверка реализации, а не гарантия отсутствия любых уязвимостей. Реальная OAuth-сессия и установка на физическом iPhone отдельно не проверялись.
