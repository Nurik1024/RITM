# Дизайн Ритма

Тёмные нейтральные поверхности, лавандовый акцент, зелёный для выполнений и приглушённый розовый для пропусков. Смысл календаря передают также символы и подписи — состояние не зависит только от цвета. Декоративные орбиты, переходы, hover и анимация победы сделаны в CSS; настройка `prefers-reduced-motion` отключает движение.

## Что изучено

- [Radix Colors](https://github.com/radix-ui/colors) и [анатомия цветовых шкал](https://www.radix-ui.com/colors/docs/palette-composition/understanding-the-scale): разделение оттенков для фона, взаимодействий, границ и текста. Это ориентир для собственных CSS-стилей; пакет не установлен и код репозитория не запускался.
- [Google Fonts / Manrope](https://github.com/google/fonts/tree/main/ofl/manrope): выбран вариативный шрифт с кириллицей и весами 200–800. Лицензия SIL OFL 1.1 сохранена в `public/fonts/OFL.txt`.
- [Fontsource](https://github.com/fontsource/fontsource): изучен подход локального размещения шрифтов. Пакеты и скрипты этого проекта не устанавливались.

## Происхождение ресурса

Загружены только Manrope TTF и OFL.txt через GitHub Contents API официального `google/fonts`. Заголовок файла проверен как TrueType, размер ограничен 500 КБ, Git blob SHA вычислен локально и сопоставлен с ответом API.

- Файл: `public/fonts/manrope-variable.ttf`
- Git blob SHA-1: `75274da58537d6123b14f2cd0c355ad4681fc2b3`
- SHA-256: `3ae11c49db0455a3cc33e37d380f20fdb8c7f8b41dc07625c177e3d87a9d6ae6`

Шрифт загружается с домена самого сайта. CSS не обращается к внешним CDN, Google Fonts API или аналитике. Совпадение хеша подтверждает происхождение и целостность конкретного файла, но не является доказательством отсутствия любых ошибок в шрифтовых парсерах. Полный репозиторий Google Fonts не клонировался, его команды не исполнялись.
